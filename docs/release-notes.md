## 使用

解压交付包后，Windows可双击 `start.cmd`。首次运行需要Node.js 24.9+、Python 3.11+和联网安装依赖；没有已有工作台时还需Git。剪辑/包装建议使用FFmpeg 8.1+，转写需要用户准备兼容的本地ASR依赖与权重。

浏览器地址：`http://127.0.0.1:3210`。在设置中配置模型连接，或提供 `DEEPSEEK_API_KEY` 环境变量。

交付包包含源码与构建产物，不包含密钥、会话、用户素材、模型权重或node_modules。安装与边界详见README、SECURITY和验收记录。
